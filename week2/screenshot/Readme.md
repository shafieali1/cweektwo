1. btn_concat_Click
This is the Concatenate button.
Purpose: It combines the First Name and Second Name into one Full Name.
Example: Mohamed + Ali → Mohamed Ali


2. btn_clear_Click
This is the Clear button.
Purpose: It clears/removes the text entered in the First Name and Second Name TextBoxes.
In short:
1 = Concatenate → Combines the names
2 = Clear → Removes the entered text
